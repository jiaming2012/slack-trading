  <action>
Create `docker-compose.prod.yaml` at the repo root that combines all services into a single production stack. Per D-10, this extends the existing observability and database compose patterns.

Services to include:

1. **eventstore.db** -- copy from `eventstoredb/docker-compose.yaml` exactly (image: eventstore/eventstore:24.2.0-jammy, same env vars, same volume mounts). Keep ports but note they are internal-only via DO Cloud Firewall.

2. **postgres** -- copy from `eventstoredb/docker-compose.yaml` but use env vars from `.env.prod` instead of hardcoded values:
   - POSTGRES_DB=${POSTGRES_DB}
   - POSTGRES_USER=${POSTGRES_USER}
   - POSTGRES_PASSWORD=${POSTGRES_PASSWORD}
   - Same volume mount for data persistence.

3. **otel-lgtm** -- based on `observability/docker-compose.yaml` with additions per D-04, D-07, D-09:
   - image: grafana/otel-lgtm
   - ports: "3000:3000" (Grafana), "4317:4317" (OTLP gRPC), "4318:4318" (OTLP HTTP)
   - environment:
     - GF_AUTH_ANONYMOUS_ENABLED=false (per D-07 -- CRITICAL, must be set)
     - GF_SECURITY_ADMIN_PASSWORD=${GF_ADMIN_PASSWORD}
     - GF_DASHBOARDS_DEFAULT_HOME_DASHBOARD_PATH=/otel-lgtm/grafana/conf/provisioning/dashboards/custom/grodt-live-simulation.json
     - SLACK_OPTION_ALERTS_WEBHOOK_URL=${SLACK_OPTION_ALERTS_WEBHOOK_URL}
   - volumes: same as observability/docker-compose.yaml (dashboard provider, dashboard JSON, alerting YAML) plus otel-lgtm-data volume
   - restart: unless-stopped

4. **grodt** -- the trading app per D-05:
   - build: context: ., dockerfile: Dockerfile
   - depends_on: postgres, eventstore.db, otel-lgtm
   - env_file: .env.prod
   - ports: "8080:8080" (REST), "5051:5051" (Twirp)
   - restart: unless-stopped

All volumes declared at bottom: otel-lgtm-data, eventstore-volume-data, eventstore-volume-logs, postgres-volume-data.

Do NOT use `version: "3.4"` -- modern Docker Compose does not require the version field.

Use `restart: unless-stopped` on all services for production resilience.

4. **PostgreSQL** -- POSTGRES_DB=playground, POSTGRES_USER=grodt, POSTGRES_PASSWORD=CHANGEME, POSTGRES_HOST=postgres, POSTGRES_PORT=5432
