    ```
    func TestReplayMatchesInMemory(t *testing.T):
      1. Start ESDB TestContainer via startESDBContainer(t, ctx)
      2. Create ESDBProducer via createESDBProducer(t, connString)

      // Create test signals with known timestamps
      3. Define 5-10 TradeSignal structs spanning a time range (e.g., every 5 minutes from T0 to T0+45m):
         - Mix of signal names (e.g., "ma_crossover", "rsi_oversold")
         - Mix of symbols (e.g., "AAPL", "MSFT")
         - Each with unique Attributes map

      // Run 1: In-memory baseline
      4. Create InMemorySignalRepository, Write all signals into it
      5. Simulate clock advancing from T0 through T0+45m in 5-min increments
      6. At each tick, call ReadPending(currentTime) and collect delivered signals
      7. Record: delivered signal count, order of delivery, signal names at each tick

      // Persist signals to ESDB
      8. Create ESDBSignalRepository via NewESDBSignalRepository(esdbProducer)
      9. Write all test signals to ESDB via esdbRepo.Write(sig) for each signal

      // Run 2: ESDB replay
      10. Read all signals back from ESDB: replaySignals := esdbRepo.GetAll()
      11. Create fresh InMemorySignalRepository, bulk-load replay signals via Write()
      12. Run same clock advancement loop (T0 through T0+45m, 5-min increments)
      13. At each tick, call ReadPending(currentTime) and collect delivered signals
      14. Record: delivered signal count, order of delivery, signal names at each tick

      // Compare
      15. Assert total signal count matches
      16. Assert signal delivery order matches (same signals at same ticks)
      17. Assert each signal's Name, Symbol, Timestamp, and Attributes match exactly
    ```

    Key implementation details:
    - Use `testing.Short()` guard: `if testing.Short() { t.Skip("requires docker") }`
    - Reuse `startESDBContainer` and `createESDBProducer` from same package (both in integration_testing package)
    - Per research pitfall 2: after reading from ESDB, signals come in append order. The InMemorySignalRepository.Write() maintains sorted insertion, so writing in any order is safe.
    - Per research pitfall 5: ESDB writes are eventually consistent. After writing all signals, the GetAll() read fetches the full stream which handles this.
    - Use `require.Equal(t, ...)` for strict comparison of signal slices
    - Use `assert.Len(t, ...)` for count checks
