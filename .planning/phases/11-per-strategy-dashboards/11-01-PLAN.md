Create two Grafana dashboard JSON files following the exact schema pattern from grodt-live-simulation.json. Each dashboard must have its own unique uid and title. Per STRAT-01, these must NOT be copies of the main dashboard -- they contain strategy-specific panels.

**Both dashboards share these template variables** (copy pattern from main dashboard):
- client_id (from grodt_orders_placed_total)
- playground_id (from grodt_orders_placed_total)
- symbol (from grodt_candles_processed_total)

Neither dashboard needs a signal_type dropdown since each is pre-filtered to its own signal type.

**grodt-mean-reversion.json** (uid: "grodt-mean-reversion", title: "Grodt Mean Reversion Strategy"):

Row 1: "Strategy Health"
- Panel: Strategy Heartbeat (table) -- `grodt_strategy_heartbeat{client_id=~"$client_id", strategy_name="mean_reversion"}` instant table showing playground_id, client_id. Hide Time/Value/__name__/job/instance columns.
- Panel: Signal Activity (timeseries) -- `sum by (symbol) (grodt_signals_generated_total{signal_type="mean_reversion", client_id=~"$client_id"})` legend={{symbol}}. Shows signal generation rate per symbol.
- Panel: Signal Direction Breakdown (stat) -- Two targets: `sum(grodt_signals_generated_total{signal_type="mean_reversion", client_id=~"$client_id"})` as "Total Signals" and same metric but showing rate via `increase(...[1h])` as "Signals (1h)".

Row 2: "Entry & Exit Activity"
- Panel: Orders Placed / Filled (timeseries, 12w) -- Same as main dashboard but pre-filtered: `grodt_orders_placed_total{environment=~"live|reconcile", client_id=~"$client_id", playground_id=~"$playground_id"}`. Two targets: Placed + Filled. Legendformat "Placed" / "Filled".
- Panel: Orders Rejected (stat, 12w) -- `increase(grodt_orders_rejected_total{...}[1h])` with green/orange/red thresholds at 0/1/5.

Row 3: "Order Detail"
- Panel: Recent Mean Reversion Orders (table, 24w) -- Loki query: `{service_name="grodt"} | logfmt | event=~"order_placed|order_filled|order_rejected" | client_id=~"$client_id" | playground_id=~"$playground_id" | line_format "{{.event}} {{.symbol}} {{.side}} qty={{.quantity}} price={{.fill_price}} | trace={{.traceID}}"` maxLines 30.

Row 4: "Market Data"
- Panel: Candles Processed by Symbol (timeseries, 24w) -- `sum by (symbol) (grodt_candles_processed_total{symbol=~"$symbol", client_id=~"$client_id"})` legend={{symbol}}.

**grodt-covered-call.json** (uid: "grodt-covered-call", title: "Grodt Covered Call Strategy"):

Row 1: "Strategy Health"
- Panel: Strategy Heartbeat (table) -- `grodt_strategy_heartbeat{client_id=~"$client_id", strategy_name="covered_call"}` instant table. Hide Time/Value/__name__/job/instance.
- Panel: Signal Activity (timeseries) -- `sum by (symbol) (grodt_signals_generated_total{signal_type="covered_call", client_id=~"$client_id"})` legend={{symbol}}.
- Panel: Signal Direction Breakdown (piechart or stat) -- Two targets: `sum(grodt_signals_generated_total{signal_type="covered_call", client_id=~"$client_id"})` total and `increase(...[1h])` hourly rate.

Row 2: "Call Selling Activity"
- Panel: Orders Placed / Filled (timeseries, 12w) -- pre-filtered to client_id/playground_id.
- Panel: Orders Rejected (stat, 12w) -- same threshold pattern.

Row 3: "Order Detail"
- Panel: Recent Covered Call Orders (table, 24w) -- Same Loki pattern as mean_reversion dashboard, filtered by client_id/playground_id.

Row 4: "Market Data"
- Panel: Candles Processed by Symbol (timeseries, 24w) -- same pattern.

**JSON conventions** (match main dashboard exactly):
- `"editable": false`
- `"schemaVersion": 39`
- `"id": null`
- `"version": 1`
- `"refresh": "30s"`
- `"time": {"from": "now-6h", "to": "now"}`
- Datasource refs: `{"type": "prometheus", "uid": "prometheus"}` and `{"type": "loki", "uid": "loki"}`
- Tags: `["grodt", "strategy", "mean_reversion"]` or `["grodt", "strategy", "covered_call"]`
- Panel IDs: sequential starting at 1
- gridPos pattern: rows at h=1/w=24, content panels use h=8 or h=10

**Key difference from main dashboard:** These dashboards link back to the main dashboard via the `"links"` array:
```json
"links": [{"title": "Main Dashboard", "url": "/d/grodt-live-sim", "type": "link"}]
```
