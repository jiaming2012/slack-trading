    ```go

        ReconcilePlayground: playground.ReconcilePlayground,
        OrderRecord:         order,
        Trade:               trade,  // Trade is set but Price/Quantity are 0
    }
    ```
    When this flows to fillPendingOrder, the order_filled log emits fill_quantity=0 and fill_price=0.

    FIX: In the order_filled log block inside fillPendingOrder (~line 436-446), derive the actual fill price and quantity. When orderFillEntry.Trade is non-nil, use the trade's values instead of the (potentially zero) Price/Quantity fields:

    ```go

    if orderFillEntry.Trade != nil {
        fillPrice = orderFillEntry.Trade.Price
        fillQuantity = orderFillEntry.Trade.Quantity
    }
    ```

    Then use fillPrice and fillQuantity in the log.Fields:
    ```go
    "fill_price":    fillPrice,
    "fill_quantity": fillQuantity,
    ```

    This way, the log always reports accurate values regardless of which code path created the ExecutionFillRequest.

    Do NOT change the ExecutionFillRequest construction sites -- the Trade field is intentionally used for the CommitPendingOrder logic. Only fix the log output.
