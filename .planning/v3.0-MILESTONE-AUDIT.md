## Critical Integration Gaps

### 1. Phase 19 Work Absent from Branch
WriteSignal, GetSignals, and GetProcessedSignals RPCs do not exist in `playground.proto`, generated stubs, or `grpc.go`. The 19-01-SUMMARY describes work that is not in the current `feature/trade-signals` branch. This severs DS-01, DS-02, DS-03, and RPC-01.

### 2. Phase 22-03 Files Missing from Disk
`covered_call_v2.py`, `wheel_v2.py`, `covered_call_signals.py`, and `wheel_signals.py` were claimed as delivered in 22-03-SUMMARY but do not exist in the working tree. MIG-01 is 3-of-5, not 5-of-5.

### 3. on_signal() Hook is Dead Code
Go correctly delivers `new_signals` in TickDelta. Python `client.py` `tick()` method never reads `new_state.new_signals` and no V2 strategy overrides `on_signal()`. V2 strategies work only because they call `produce_signals()` inline — bypassing the TradeSignal framework's signal consumption path entirely.

### 4. DatasourceHeartbeat Never Instantiated
The class exists (Phase 23-02) and the Grafana alert rule exists, but no datasource script imports or instantiates `DatasourceHeartbeat`. OBS-02 alert will never fire.
