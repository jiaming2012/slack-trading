<objective>
Create a standalone Python script that authenticates with the Zoho Calendar API, fetches events from a "Payments" calendar, and lists upcoming events for the next 7 days.

Purpose: Quick visibility into upcoming payment-related calendar events without opening the Zoho web UI.
Output: A runnable Python script at `scripts/zoho_calendar_payments.py`
</objective>

<context>
This is a standalone utility script — not part of the trading platform's core codebase. It uses the Zoho Calendar API (OAuth2) and prints results to stdout.

Zoho Calendar API docs: https://www.zoho.com/calendar/help/api/
Authentication: Zoho uses OAuth2 with a refresh token flow. The script will need:
- ZOHO_CLIENT_ID
- ZOHO_CLIENT_SECRET
- ZOHO_REFRESH_TOKEN
- ZOHO_CALENDAR_ID (the Payments calendar's unique ID)

These will be read from environment variables (or a .env file via python-dotenv).
</context>

<tasks>

<task type="auto">
  <name>Task 1: Create Zoho Calendar payments script</name>
  <files>scripts/zoho_calendar_payments.py</files>
  <action>
Create a standalone Python script that:

1. **Authentication**: Uses Zoho OAuth2 refresh token flow to get an access token.
   - POST to `https://accounts.zoho.com/oauth/v2/token` with grant_type=refresh_token, client_id, client_secret, refresh_token
   - Extract access_token from response

2. **Fetch calendar events**: Call Zoho Calendar API to get events for the next 7 days.
   - GET `https://calendar.zoho.com/api/v1/calendars/{calendar_id}/events`
   - Pass query params: `range` with start (today) and end (today + 7 days) in ISO format
   - Include `Authorization: Zoho-oauthtoken {access_token}` header

3. **Display**: Print a formatted list of events showing:
   - Event title
   - Date and time (formatted nicely for terminal)
   - Duration or end time
   - Any notes/description (truncated to 100 chars)

4. **Configuration**: Read from env vars with python-dotenv fallback:
   - ZOHO_CLIENT_ID
   - ZOHO_CLIENT_SECRET
   - ZOHO_REFRESH_TOKEN
   - ZOHO_CALENDAR_ID

5. **Error handling**: Clear error messages for missing env vars, auth failures, and API errors.

Use only stdlib + `requests` + `python-dotenv` (no heavy dependencies). Include a `if __name__ == "__main__"` block. Add a `--days N` CLI argument (default 7) via argparse.

Add a docstring at the top explaining required env vars and usage.
  </action>
