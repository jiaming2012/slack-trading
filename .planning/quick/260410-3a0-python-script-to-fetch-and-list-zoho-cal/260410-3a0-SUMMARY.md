# Quick Task 260410-3a0: Summary

## What was built

Standalone Python script at `scripts/zoho_calendar_payments.py` that fetches and displays upcoming events from a Zoho Calendar "Payments" calendar.

## Features

- OAuth2 refresh token authentication with Zoho
- Fetches events for configurable date range (default 7 days)
- Formatted terminal output: title, date, time, description
- `--days N` CLI argument for flexible lookback
- Reads credentials from env vars or `.env` file
- Clear error messages for auth failures, missing config, API errors

## Dependencies

- `requests` (HTTP client)
- `python-dotenv` (optional, for .env file loading)

## Required Environment Variables

- `ZOHO_CLIENT_ID`
- `ZOHO_CLIENT_SECRET`
- `ZOHO_REFRESH_TOKEN`
- `ZOHO_CALENDAR_ID`
