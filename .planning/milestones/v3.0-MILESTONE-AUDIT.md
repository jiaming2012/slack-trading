## Actionable Gaps (3 items, all medium/low severity)

### 1. SIG-02: Python place_order() missing signal_id (Medium)

**File:** `src/clients/python/engine/client.py:639`
**Fix:** Add `signal_id: str = None` parameter to `place_order()`, set `request.signal_id = signal_id` before RPC call.
**Impact:** Signal-to-order audit trail not capturable from Python. Go side fully wired.

### 2. OBS-01: Grafana label mismatch (Medium)

**Files:** `observability/dashboards/grodt-live-simulation.json:599,875,882`, `grodt-mean-reversion.json`, `grodt-covered-call.json`
**Fix:** Either rename OTel attribute in `grpc.go:1586` from `signal_name` to `signal_type`, or update all dashboard query expressions to use `signal_name`.
**Impact:** Signal panels show empty data for signals produced via WriteSignal RPC.

### 3. MIG-01: Stale diff test @patch decorators (Low)

**Files:** 4 test files in `src/clients/python/tests/test_*_diff.py`
**Fix:** Update `@patch('strategies.<v1_module>.*')` to `@patch('deprecated.<v1_module>.*')` in all decorators.
**Impact:** 15/26 diff tests fail. Strategies themselves work correctly — only test mocking paths are wrong.
