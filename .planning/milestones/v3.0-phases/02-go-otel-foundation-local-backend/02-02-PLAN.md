  <action>
    **Create `observability/docker-compose.yaml`** per D-01 (separate compose file) and D-02 (grafana/otel-lgtm image):

    ```yaml
    version: "3.4"

    services:
      otel-lgtm:
        image: grafana/otel-lgtm
        container_name: otel-lgtm
        ports:
          - "3000:3000"    # Grafana UI
          - "4317:4317"    # OTLP gRPC receiver
          - "4318:4318"    # OTLP HTTP receiver
        volumes:
          - otel-lgtm-data:/data

    volumes:
      otel-lgtm-data:
    ```

    The grafana/otel-lgtm image bundles:
    - OTel Collector (pre-configured to route traces->Tempo, logs->Loki, metrics->Prometheus) -- satisfies BACK-02
    - Grafana with Loki, Tempo, Prometheus auto-provisioned as data sources -- satisfies BACK-03
    - All five components start with a single `docker compose up` -- satisfies BACK-01

    Per D-03: EventStoreDB is NOT part of this stack.

    **Update `taskfile.yml`** -- add these tasks following the existing `db:start` pattern:

    ```yaml
    observability:start:
      desc: "Start observability stack (Grafana, Tempo, Loki, Prometheus, OTel Collector)"
      cmds:
        - 'docker compose -f observability/docker-compose.yaml up -d'
      dir: ${PROJECT_DIR}

    observability:stop:
      desc: "Stop observability stack"
      cmds:
        - 'docker compose -f observability/docker-compose.yaml down'
      dir: ${PROJECT_DIR}

    observability:logs:
      desc: "Show observability stack logs"
      cmds:
        - 'docker compose -f observability/docker-compose.yaml logs -f'
      dir: ${PROJECT_DIR}
    ```

    Place these tasks after the existing `db:*` tasks for logical grouping.
  </action>
