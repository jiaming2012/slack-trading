**Step 2: Create Cloud Firewall**
Use DO MCP to create a Cloud Firewall per research anti-patterns (DO NOT use UFW -- Docker bypasses it):
- Name: grodt-prod-firewall
- Inbound rules:
  - TCP port 22 from 0.0.0.0/0,::/0 (SSH)
  - TCP port 3000 from 0.0.0.0/0,::/0 (Grafana UI)
  - ICMP from 0.0.0.0/0,::/0 (ping)
- Outbound rules:
  - TCP all ports to 0.0.0.0/0,::/0
  - UDP all ports to 0.0.0.0/0,::/0
  - ICMP to 0.0.0.0/0,::/0
- Attach to grodt-prod droplet

**Step 3: Note the droplet IP address** -- needed for SSH and Grafana access.

Record the droplet IP for subsequent tasks.

  <action>
SSH into the droplet and deploy the full stack. Use the droplet IP from Task 2.

**Step 1: SSH into droplet and create swap file** (prevents OOM during Docker build per research pitfall 1):
```bash
ssh root@<DROPLET_IP> "fallocate -l 2G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile && echo '/swapfile none swap sw 0 0' >> /etc/fstab"
```

**Step 2: Clone the repository:**
```bash
ssh root@<DROPLET_IP> "cd /opt && git clone https://github.com/jiaming2012/slack-trading.git"
```
If the repo is private, the user may need to provide a GitHub token or deploy key.

**Step 3: Create .env.prod from template:**
```bash
ssh root@<DROPLET_IP> "cp /opt/slack-trading/.env.prod.template /opt/slack-trading/.env.prod"
```
Then the user needs to fill in secrets (Tradier keys, Polygon key, Slack webhook, Grafana password, Postgres password). This will be handled in the checkpoint task.

**Step 4: Handle base Docker image** (research pitfall 4):
The Dockerfile uses `FROM ewr.vultrcr.com/grodt/grodt-base-image-2:3.9.0` which may not be accessible from DO. Test first:
```bash
ssh root@<DROPLET_IP> "docker pull ewr.vultrcr.com/grodt/grodt-base-image-2:3.9.0"
```
If this fails (unauthorized/not found), build base images on the droplet:
```bash
ssh root@<DROPLET_IP> "cd /opt/slack-trading && docker build -t grodt-base-image:3.9.0 -f Dockerfile.base . && docker build -t grodt-base-image-2:3.9.0 -f Dockerfile.base2 ."
```
Then update the Dockerfile FROM line on the droplet to use the local image name.
NOTE: Building base images takes 15-30 minutes. This is a one-time cost.

**Step 5: Build and start the stack:**
```bash
ssh root@<DROPLET_IP> "cd /opt/slack-trading && docker compose -f docker-compose.prod.yaml up -d --build"
```

**Step 6: Verify services are running:**
```bash
ssh root@<DROPLET_IP> "docker compose -f docker-compose.prod.yaml ps"
```
All 4 services should show as "Up" or "running".

**Step 7: Verify Grafana responds:**
```bash
curl -s -o /dev/null -w '%{http_code}' http://<DROPLET_IP>:3000
```
Should return 302 (redirect to login) -- confirming Grafana is accessible and anonymous auth is disabled (per D-07).
