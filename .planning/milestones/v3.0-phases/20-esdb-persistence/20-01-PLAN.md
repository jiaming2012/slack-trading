**Step 2: Create ESDBSignalRepository.**

Create `src/go/backtester-api/models/signal_repository_esdb.go` with:

```go
package models
```

The struct:
- `ESDBSignalRepository` with fields: `esdbProducer *eventproducers.EsdbProducer`, `mutex sync.Mutex`
- Constructor: `NewESDBSignalRepository(esdbProducer *eventproducers.EsdbProducer) *ESDBSignalRepository`

Implement `ISignalRepository`:

- **Write(signal)**: Call `r.esdbProducer.Save(context.Background(), signal)` to write-through to ESDB immediately. Return error on failure.

- **ReadPending(upTo time.Time)**: This is for live mode where signals come from ESDB. Read ALL events from the `trade-signals` stream using `eventservices.FetchAll[*eventmodels.TradeSignal](ctx, r.esdbProducer.GetClient(), &eventmodels.TradeSignal{})`. Filter results where `signal.Timestamp` is `<= upTo`. Note: For live mode, ReadPending reads the full stream each time. This is acceptable at expected volume (<1000 signals/day per D-01). No cursor tracking needed for ESDB -- the stream IS the persistence layer.

- **GetAll()**: Same as ReadPending but without the time filter. Read all events from ESDB stream via `FetchAll`.

Import `context`, `sync`, `time`, `github.com/jiaming2012/slack-trading/src/go/eventmodels`, `github.com/jiaming2012/slack-trading/src/go/eventproducers`, `github.com/jiaming2012/slack-trading/src/go/eventservices`.

**IMPORTANT**: The `FetchAll` generic requires a `SavedEvent` constraint. `*eventmodels.TradeSignal` satisfies this via `GetSavedEventParameters()`. However, `FetchAll` returns `[]T` not `[]*T`. Since `TradeSignal` has pointer receiver methods on `SavedEvent` (via `BaseRequestEvent`), you may need to use `FetchAll[*eventmodels.TradeSignal]` -- check the generic constraint. If `FetchAll` cannot work with pointer types directly, read the stream manually using `esdb.Client.ReadStream()` + JSON unmarshal loop (follow the pattern in `FetchAll` body).
