**4. Implement handler: `WriteSignal`** (add to grpc.go):

Per D-01 and D-02 — signals are GLOBAL, no playground_id in request. Steps:
1. Validate signal name via `eventmodels.SignalName(req.Name).Validate()` — return Twirp InvalidArgument on error
2. Convert `req.Attributes` (map[string]string) to `map[string]interface{}` for domain model
3. Create `eventmodels.NewTradeSignal(name, eventmodels.StockSymbol(req.Symbol), req.Timestamp.AsTime(), attrs)`
4. Write to `s.globalSignalRepo.Write(signal)` — return Twirp Internal on error
5. Increment OTel counter: `if telemetry.SignalsProduced != nil { telemetry.SignalsProduced.Add(ctx, 1, metric.WithAttributes(attribute.String("signal_name", req.Name), attribute.String("symbol", req.Symbol))) }`
6. Log with `log.WithFields(log.Fields{"event": "signal_produced", "signal_id": signal.ID.String(), "name": req.Name, "symbol": req.Symbol}).Info("signal produced via WriteSignal")`
7. Return `&pb.WriteSignalResponse{SignalId: signal.ID.String()}`

Use `"github.com/twitchtv/twirp"` for error codes: `twirp.InvalidArgumentError("name", err.Error())`.

**5. Implement handler: `GetSignals`** (add to grpc.go):

Reads from `s.globalSignalRepo.GetAll()`, applies optional filters from request (name, symbol, from_timestamp, to_timestamp), converts to `[]*pb.TradeSignalProto` using the same conversion pattern from NextTick handler (lines ~952-966 of grpc.go). Return `&pb.GetSignalsResponse{Signals: filtered}`.

Filtering logic (applied in-memory since GetAll returns all signals):
- If `req.Name != nil`: filter where `string(sig.Name) == *req.Name`
- If `req.Symbol != nil`: filter where `string(sig.Symbol) == *req.Symbol`
- If `req.FromTimestamp != nil`: filter where `!sig.Timestamp.Before(req.FromTimestamp.AsTime())`
- If `req.ToTimestamp != nil`: filter where `!sig.Timestamp.After(req.ToTimestamp.AsTime())`

**6. Implement handler: `GetProcessedSignals`** (add to grpc.go):

Per D-03 and RPC-01 — reads per-playground consumed signals:
1. Parse `req.PlaygroundId` as UUID — return Twirp InvalidArgument on error
2. Call `s.dbService.GetPlayground(playgroundID)` — return Twirp NotFound on error
3. Get signal repo: `pg.GetSignalRepo()` — if nil, return empty response
4. Call `signalRepo.GetAll()` — these are signals already consumed by this playground
5. Apply same optional filters as GetSignals (name, symbol, from_timestamp, to_timestamp)
6. Convert to proto and return `&pb.GetProcessedSignalsResponse{Signals: filtered}`
