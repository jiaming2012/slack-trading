Phase 8 established that all Go OTel metrics now emit `client_id` as a label via PlaygroundAttrs(env, accountType, clientID). The Prometheus metrics `grodt_orders_placed_total`, `grodt_orders_filled_total`, `grodt_orders_rejected_total`, `grodt_candles_processed_total`, and `grodt_signals_generated_total` all have `client_id` alongside `playground_id`.

The dashboard uses Prometheus (uid: "prometheus") and Loki (uid: "loki") datasources.
Current template variable `playground_id` queries `label_values(grodt_orders_placed_total, playground_id)`.

Structured log fields available in Loki (from order_placed logs):
- event, playground_id, order_id, symbol, side, quantity, order_type, environment, account_type, client_id

For trace_id: The OTel Collector in grafana/otel-lgtm adds `traceID` as a detected field on OTLP log records. Include `{{.traceID}}` in Loki line_format templates -- it will render when trace context is present on the log record.
