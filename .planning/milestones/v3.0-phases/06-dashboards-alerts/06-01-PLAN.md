Create `observability/dashboards/grodt-live-simulation.json` -- a complete Grafana dashboard JSON model.

**Dashboard metadata:**
- uid: "grodt-live-sim"
- title: "Grodt Live Simulation"
- editable: false (provisioned)
- refresh: "30s"
- timezone: "browser"
- schemaVersion: 39

**Template variable (per D-02, D-03):**
A `playground_id` variable using Prometheus label_values:
- name: "playground_id"
- type: "query"
- datasource: {"type": "prometheus", "uid": "prometheus"}
- query: "label_values(grodt_orders_placed_total, playground_id)"
- includeAll: true
- allValue: ".*"
- current: {"text": "All", "value": "$__all"}
- refresh: 2 (on time range change)

**Row 1: System Health (per D-01)**
Three stat panels side by side:

Panel 1 - "Go Server Uptime":
- type: stat
- datasource: prometheus
- PromQL: `grodt_heartbeat_uptime_seconds`
- unit: "s" (duration seconds)
- thresholds: green >=0

Panel 2 - "Python Strategy Heartbeat":
- type: stat
- datasource: prometheus
- PromQL: `grodt_strategy_heartbeat`
- mappings: 1="Alive" (green), 0="Dead" (red)
- thresholds: red=0, green=1

Panel 3 - "Active Live Playgrounds":
- type: stat
- datasource: prometheus
- PromQL: `grodt_heartbeat_active_playgrounds{environment="live"}`
- thresholds: green >=0

**Row 2: Order Activity (per D-01)**
Three panels:

Panel 4 - "Orders Placed / Filled Rate":
- type: timeseries
- datasource: prometheus
- Two queries:
  - A: `rate(grodt_orders_placed_total{environment=~"live|reconcile", playground_id=~"$playground_id"}[5m])`  legendFormat: "Placed"
  - B: `rate(grodt_orders_filled_total{environment=~"live|reconcile", playground_id=~"$playground_id"}[5m])`  legendFormat: "Filled"

Panel 5 - "Orders Rejected (1h)":
- type: stat
- datasource: prometheus
- PromQL: `increase(grodt_orders_rejected_total{environment=~"live|reconcile", playground_id=~"$playground_id"}[1h])`
- thresholds: green=0, orange=1, red=5

Panel 6 - "Recent Order Events":
- type: table
- datasource: loki
- LogQL: `{service_name="grodt-server"} | logfmt | event=~"order_placed|order_filled|order_rejected" | line_format "{{.event}} {{.symbol}} {{.side}} qty={{.quantity}}"`
- limit: 20

**Row 3: Market Data (per D-01)**
Two panels:

Panel 7 - "Candles Processed Rate":
- type: timeseries
- datasource: prometheus
- PromQL: `rate(grodt_candles_processed_total[5m])`

Panel 8 - "Signals Generated Rate":
- type: timeseries
- datasource: prometheus
- PromQL: `rate(grodt_signals_generated_total[5m])`

**Row 4: Positions (per D-01, DASH-03)**
Two panels:

Panel 9 - "Open Orders":
- type: stat
- datasource: prometheus
- PromQL: `grodt_heartbeat_open_orders`
- thresholds: green >=0

Panel 10 - "Position Details":
- type: table
- datasource: loki
- LogQL: `{service_name="grodt-server"} | logfmt | event="order_placed" | line_format "{{.playground_id}} | {{.symbol}} | {{.side}} | qty={{.quantity}}"`
- limit: 50

**Grid layout:**
- Each row is a collapsible row panel (type: "row")
- Stat panels: gridPos height=8, width=8 (3 across = 24)
- Time series panels: gridPos height=10, width=12 (2 across = 24)
- Table panels: gridPos height=10, width=24 (full width)

Use sequential panel IDs starting from 1. Each row panel gets its own ID too.

**IMPORTANT:** Validate the JSON is syntactically correct. The file will be 300-500 lines. Use standard Grafana dashboard JSON v1 schema (NOT v2 experimental).
